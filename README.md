# Classpaper-v2

ClassPaper 是一个用 Go 语言开发的桌面壁纸程序，可以将任意网页作为动态壁纸显示在桌面，并支持托盘菜单操作、桌面穿透、自动重载等功能。

---

## 功能特性

- 将任意网页作为桌面壁纸显示
- 支持桌面穿透（窗口嵌入桌面底层）
- 托盘菜单：网页重载、桌面穿透、重启网页显示、打开设置、重启程序、退出
- 支持自定义浏览器路径
- 支持自动定时修正窗口状态
- 日志输出到 app.log 文件

---

## 使用方法

1. 克隆本仓库到本地
2. 安装 Go 1.16 及以上版本
3. 安装依赖（首次运行会自动 go get，或手动 `go mod tidy`）
4. 编辑 `config.toml` 文件，配置网页 URL 和浏览器路径
5. 运行程序：
   ```bash
   go run main.go
   ```
6. 程序启动后会在系统托盘显示图标，可通过托盘菜单进行操作

---

## 配置文件说明

配置文件为 `config.toml`，支持两种写法：

**推荐写法：**

```toml
url = "http://example.com"         # 要显示的网页URL
browser_path = ""                  # 浏览器可执行文件路径（可选，留空用默认浏览器）
```

**或带区块写法：**

```toml
[default]
url = "http://example.com"
browser_path = ""
```

---

## 托盘菜单说明

- **重载网页**：强制刷新壁纸网页内容
- **设置程序桌面穿透**：重新设置窗口为桌面壁纸（如被系统抢占可手动修复）
- **重启网页显示程序**：关闭并重新打开网页壁纸窗口
- **设置**：打开设置窗口（需有 `setting` 可执行文件）
- **重启程序**：重启整个 ClassPaper 程序
- **退出程序**：完全退出并关闭所有窗口

- 所有运行日志会输出到 `app.log` 文件，便于排查问题

## 依赖项

- `github.com/getlantern/systray`：系统托盘菜单
- `github.com/zserge/lorca`：嵌入式浏览器窗口
- `github.com/pelletier/go-toml`：TOML 配置解析
- Go 1.16 及以上

---

## 文件结构

- `main.go`：主程序入口及全部核心逻辑
- `config.toml`：主配置文件
- `res/`：静态资源目录
- `icon/`：图标资源
- `app.log`：运行日志

---

## 注意事项

- Windows 下首次运行会自动切换控制台编码为 UTF-8
- 桌面穿透功能依赖 Windows API，仅支持 Windows 系统
- 设置窗口需有 `setting` 可执行文件（可选）
