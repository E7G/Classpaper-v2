# Classpaper-v2

ClassPaper 是一个用 Go 语言开发的桌面壁纸程序，可以将任意网页作为动态壁纸显示在桌面，并支持托盘菜单操作、桌面穿透、自动重载等功能。

---

## 功能特性

- 将任意网页作为桌面壁纸显示
- 支持桌面穿透（窗口嵌入桌面底层）
- 托盘菜单：网页重载、桌面穿透、重启网页显示、打开设置、重启程序、退出
- 支持自定义浏览器路径
- 支持自动定时修正窗口状态
- 日志输出到 app.log 文件

---

## 前端设置与功能优化（2025年7月重点更新）

- **设置界面美化**：整体风格更简洁，tab切换流畅，课程表tab与壁纸tab均有美化，去除斑马纹，保留圆角和悬停高亮。
- **进度条描述与百分比显示**：进度条下方描述支持自定义，百分比可切换“剩余/已过”两种方式。
- **重置按钮弹窗**：重置按钮增加自定义对话框确认弹窗，防止误操作。
- **智能推算课程时间**：支持一键自动补全后续节次时间，兼容input type=time格式（如08:50），无需手动填写全部节次。
- **课表高亮优化**：动态高亮当前课程，避免死板高亮第6格。
- **状态提示优化**：每次调用showStatus都能弹出提示，消息显示更及时。

## 壁纸管理与美化

- **壁纸tab结构优化**：壁纸列表支持缩略图、卡片分组，按钮美化，切换间隔可自定义。
- **壁纸切换体验提升**：切换时平滑过渡，支持定时自动切换。

## BUG修复与兼容性

- 修复智能推算时间格式导致的input type=time报错（如8:50→08:50）。
- 修复状态提示（showStatus）消息不显示的问题。
- 优化课表高亮逻辑，动态高亮当前课程。
- 处理课表不显示、JS报错等常见问题。
- **托盘高DPI适配**：使用多分辨率ico文件，Windows会自动适配高DPI，无需修改Go代码。

---

## 常见问题与排查

- 课表不显示/JS报错：请在设置点击在浏览器打开调试后，在弹出的浏览器窗口按F12打开开发者工具，查看Console报错信息，按提示修正。
- 消息不显示：确保showStatus函数被正确调用，且status元素未被隐藏。
- 壁纸切换无效：检查壁纸路径、图片格式及切换间隔设置。

## 使用方法

1. 克隆本仓库到本地
2. 安装 Go 1.16 及以上版本
3. 安装依赖（首次运行会自动 go get，或手动 `go mod tidy`）
4. 编辑 `config.toml` 文件，配置网页 URL 和浏览器路径
5. 运行程序：
   ```bash
   go run main.go
   ```
6. 程序启动后会在系统托盘显示图标，可通过托盘菜单进行操作

---

## 配置文件说明

配置文件为 `config.toml`，支持两种写法：

**推荐写法：**

```toml
url = "http://example.com"         # 要显示的网页URL
browser_path = ""                  # 浏览器可执行文件路径（可选，留空用默认浏览器）
```

**或带区块写法：**

```toml
[default]
url = "http://example.com"
browser_path = ""
```

## 托盘菜单说明

- **重载网页**：强制刷新壁纸网页内容
- **设置程序桌面穿透**：重新设置窗口为桌面壁纸（如被系统抢占可手动修复）
- **重启网页显示程序**：关闭并重新打开网页壁纸窗口
- **设置**：打开设置窗口（需有 `setting` 可执行文件）
- **重启程序**：重启整个 ClassPaper 程序
- **退出程序**：完全退出并关闭所有窗口

---

## 文件结构

- `main.go`：主程序入口及全部核心逻辑
- `config.toml`：主配置文件
- `res/`：静态资源目录（含 settings.html、js、css、壁纸等）
- `icon/`：图标资源（含多分辨率ico以适配高DPI）
- `app.log`：运行日志

---

## 注意事项

- Windows 下首次运行会自动切换控制台编码为 UTF-8
- 桌面穿透功能依赖 Windows API，仅支持 Windows 系统
